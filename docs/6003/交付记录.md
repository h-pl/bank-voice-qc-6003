# 6003 实施与验收

依据：[6003 PRD](https://acnc6zeentra.feishu.cn/wiki/HkzuwVO6RifzR8kMiLRcdtsJnAd)。独立目录 `projects/bank-voice-qc-6003`；原 6001 目录保留。

## 行为

- 12 个指标、12 个资源、12 条规则一一对应；指标启停，资源直接保存。
- 检测角色、阶段、次数、时长和特征参数归资源；策略管理规则关联、等级、提醒和流程。
- 多条规则共用策略；重复占用校验；默认策略兜底；特殊流程派单至质检员，无效流程回主管并记录原因。
- 一通话一告警；不同问题分别办理。动态等级、办理进度、关闭与重开保留原因记录。
- 报表增加告警通话、处理中/已关闭及高/中/低等级统计，共用下钻与导出数据。
- 检测依据附在问题及检测批次中；配置更新后，原问题依据和办理记录保持可查。

保留三角色权限、复核、申诉、整改、退回、材料、期限与录音联动回归测试。原配置发布、引用切换与旧样例迁移用例已由直接保存、一一对应和聚合测试替代。

数据层保持本地交互原型。检测接入入口为 `ingestDetection`，完成预置检测时通过 `replayDetection` 处理已有观察事实。真实模型与组织、附件、外部消息接入沿 PRD 待落实事项推进。默认等级和特殊流程参数为可验收的初始设置。
