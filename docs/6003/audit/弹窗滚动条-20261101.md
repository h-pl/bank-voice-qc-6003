# 弹窗滚动条统一修复 · 2026-11-01

原因：共用 workspace-system.css 的原生滚动条保留浅灰轨道和滚动槽，弹窗正文、资源表格与现有 Radix ScrollArea 表现不一致。

实现：所有 DialogContent 接入 DialogScrollbars；原生滚动容器保留 DOM、滚动行为、内容、状态和焦点，只覆盖滚动条显示。已有 ScrollArea 继续使用原组件；嵌套原生文本域同样接入。动态新增内容、输入、窗口缩放、条件字段变化由 MutationObserver / ResizeObserver 更新。只有具备覆盖滑块的容器隐藏原生滚动条，不全局隐藏页面滚动条。

视觉与交互：中灰 #808080，横纵8px，透明轨道，覆盖布局无滚动槽。停止滚动800ms后180ms淡出；悬停滑块、拖动期间保持可见。上下内缩8px、右/下内缩4px，固定表头区域避让；隐藏时滑块不截获点击，只有显示的滑块接受拖动。无溢出不显示，不新增无效键盘停靠点。父弹窗被覆盖时隐藏其滚动层。卸载、指针取消与窗口失焦清理拖动、观察器和计时器。

验证：
- 类型检查和改动文件 ESLint 通过。
- 1280×720 实测12种业务资源的查看/编辑，共24个状态，所有实际溢出容器均已接入，页脚在视口内。
- 实测10种业务指标规则编辑弹窗、列表展示设置、预警策略、查看规则与嵌套查看资源，实际溢出容器无遗漏；短弹窗无滑块。
- 实测告警记录、命中规则与业务依据、直接提醒坐席、确认误报并归档、转人工复核。未提交业务动作；隔离上下文中的输入修改均丢弃。
- 纵向滑块实际8px、rgb(128,128,128)；空闲opacity=0，滚动/悬停opacity=1。持续悬停和拖动超过1.1秒仍可见；松开并离开后隐藏。拖到末尾scrollTop=251/max=251；Home到0、End到251。显隐前后正文宽高不变。
- 专业性编辑临时增加步骤形成横向溢出，拖动到scrollLeft=368/max=368；未保存。横纵独立运行。
- 长文本输入框clientHeight=70、scrollHeight=1382，输入后动态接入，滚动正常。
- 嵌套弹窗：下层滚动层visibility=hidden，上层visible，关闭恢复原有层级。
- 高对比模式滑块使用系统色且可见；减少动态效果模式transition-duration=0s。拖动中窗口失焦后恢复空闲隐藏。

范围：本地6003公共Dialog组件；未部署线上。旧滚动条截图由本记录截图替代，其他业务数据与办理行为不变。
