# 规则 UI 细节调整 · 2026-11-01

## 最终页面

- 左侧：规则名、可点击指标标签、关联资源、预警策略；开关与预警策略同一行，无启停文字；移除底部加载数量提示。
- 右侧：规则 → 资源 → 策略。移除规则编号、重复指标区、预置适用业务与检查目标、详情开关及重复执行说明。
- 规则条件展示实际阶段范围、次数/统计窗口、持续时长和语速阈值；编辑继续使用既有保存和校验逻辑。
- 规则编号在关联规则、证据、原始结论及配置修改记录中替换为名称。内部标识及历史关联保持原值。

## PRD 依据

PRD.txt「规则：由指标与资源配置形成」明确检测条件在指标规则编辑维护。「预警策略：规则关联、等级、提醒与流程」明确主管在策略页的适用规则字段维护关联，指标详情只读展示并查看策略。本轮对齐字段名称和入口，保持该配置归属。

适用业务、检查目标原先来自预置规则数据，缺少对应编辑项；移除详情中的这两项说明，业务任务范围继续通过任务设置维护，现有范围筛选逻辑保留。
