五、字段条件与布局变化
所有阶段和触发参数都属于各自检测条件，修改一行只更新该行。

1. 检测条件
固定顺序：身份不匹配 → 未注册声纹 → 无法确认身份。
复选框和条件名称构成同一点击热区；行空白和参数控件各自响应自身操作。
取消勾选：该行保留原位置，参数禁用并变浅；保留参数值，保存后该条件停用。
重新勾选：恢复该行参数；首次启用缺少历史配置的条件时，阶段为全程、方式为单次命中。
允许临时全部取消；保存时显示「请至少选择一项检测条件」，焦点定位到条件选择区域。
Info：选择需要检测的异常；每项独立配置阶段与触发方式，满足任一已选条件后执行对应预警策略。

2. 检测阶段
选项：全程 / 开场 / 服务中 / 结束。
全程：只显示选择器。
开场：选择器下显示「开始后 [30] 秒内」。映射 stageSeconds，1–3600 的整数。
结束：选择器下显示「结束前 [30] 秒内」。映射 stageSeconds，1–3600 的整数。
服务中：选择器下依次显示「开始 [30] 秒后」「结束前 [30] 秒截止」。分别映射 middleStartSeconds、middleEndSeconds，0–3600 的整数。
阶段区间按既有检测逻辑计算；本次只优化参数表达与位置。

3. 触发方式
声纹规则只提供「单次命中 / 累计次数」。
单次命中：只显示选择器。
累计次数：选择器下依次显示「累计 [2] 次」「统计窗口 [60] 秒 (Info)」。
累计次数映射 count，1–1000 的整数；统计窗口映射 windowSeconds，0–3600 的整数。
统计窗口 Info：填 0 时统计整通通话；其他值为指定秒数内的累计次数。
首次切换为累计次数时沿用现有默认值：1 次、统计窗口 0 秒；已有值优先恢复。
当前选择暂时用不到的参数隐藏并保留，切回对应选项时恢复，保存时按现有条件模型完整保留。

4. 修改说明
选填，沿用单行输入。跟随本次规则修改提交；留空由现有保存逻辑生成调整记录说明。
只改说明、条件没有变化时，保存按钮保持禁用。

六、按钮与反馈
[保存规则] 固定右下角，为主按钮；无条件变化时禁用。
点击后校验所有已选条件：至少选一项、参数必填、合法整数且在范围内；未选条件保留参数并跳过有效性校验。
数值清空时保留空输入，显示必填错误；错误显示在对应字段下，聚焦首个错误字段。
提交期间显示「保存中…」并阻止重复提交；完成前保持编辑值稳定。
保存成功后配置直接生效，后续检测使用新配置；历史检测依据保留。
保存只更新当前规则的检测条件和修改记录；资源内容与策略配置由各自入口维护。
保存失败：弹窗保持打开，保留输入，展示实际错误并允许重试。
并发更新：显示「配置已更新，请关闭后重新编辑」，暂停本次保存，沿用现有版本校验。

[取消] 固定在保存按钮左侧：直接关闭并丢弃此次输入，再次打开读取已保存值。
[×] / Escape：无修改直接关闭；有条件修改或填写说明时，沿用底部放弃确认：

规则修改尚未保存，是否放弃？
                                       [继续编辑] [放弃修改]

[继续编辑]：恢复常规底部按钮，保留当前输入。
[放弃修改]：关闭弹窗、丢弃输入、焦点回到编辑入口。
确认期间暂停原表单提交；遮罩点击不关闭弹窗。

七、边界与可访问性
已有配置为空：三个条件均以未选状态展示，用户选择后才能保存；避免打开时自动写入默认配置。
仅主管可编辑；打开期间权限变化时禁用配置与保存，并提示「仅主管可维护配置」。
字段的可访问名称包含条件名，例如「身份不匹配 检测阶段」；错误与对应字段关联。
Tab 按行访问复选框、阶段、阶段参数、触发方式、触发参数；未选行只保留复选框可聚焦。
复选框支持 Space，下拉支持键盘选择；焦点限制在弹窗内，关闭后返回入口。
检测条件只有三项，保持全部可见；长修改说明在输入内滚动，复杂条件通过正文滚动承接。
